- **21:20:** explicit repair-and-reset restores all challenge allocations; preparation/repair is not automatically a challenge action.
- **~27:40:** extra user-authorised erase increases the remaining ability to correct the ignition path. The video alone does not prove exactly how many discrete low-level browser strokes were executed, so remaining-budget arithmetic beyond the user's explicit statements should be qualified.
- **Task supersession:** fire avoidance applies to the initial garden request. Later deliberate ignition is **not** a violation of that earlier brief.
- **Intent / action / outcome:** “the agent announced ignition,” “the agent edited a divider,” and “a sustained fire visibly spread” are three separate propositions. User correction is strong evidence, but not a cell-identity readout.

## How to use this ledger

For a new benchmark, freeze a fresh, written challenge specification and explicitly distinguish setup, repair and challenge operations. Do **not** replay the exact user messages as instructions to the new agent without permission. Track the current budget as state. If comparing Luna with a later agent without human assistance, report how removing live human corrections changes the task difficulty rather than silently giving that agent information the original agent received mid-session.
